# Viandly 0.9.0-beta.20

Released: July 31, 2026

This beta update makes common recipe work easier to begin and easier to understand.

## Highlights

- Recipe creation now starts from one consistent workflow, with optional AI development available
  from the recipe form.
- Shopping lists are now first-class working documents. Create a named list, combine ingredients
  from multiple recipes, add individual items, and edit quantities and notes in place.
- Desktop, tablet, and installed-app navigation is more consistent, with cleaner responsive recipe
  actions and consistent Import controls.
- Help for recipes, imports, collections, shopping lists, account data, and plan management has been
  expanded and updated to match the current application.
- Account data management now includes groundwork for a clearly explained future subscription
  downgrade and retained-library process.

## Billing Status

Subscriptions and checkout remain disabled during the closed beta. This release does not accept
payments, present an upgrade action, or change testers' existing beta access.

## Tester Guidance

- Try creating a recipe directly and with AI assistance.
- Build one shopping list from multiple recipes, then add and edit a standalone item.
- Verify recipe actions and bottom navigation remain readable on a tablet or phone.
- Report Help instructions that do not match the page or workflow they describe.

## Compatibility

Existing recipes, images, imports, cookbooks, shopping lists, archives, authentication methods, and
beta entitlements remain compatible.
