# Viandly 0.9.0-beta.19

Released: July 28, 2026

This beta update completes Viandly's privacy-bounded production error-monitoring rollout.

## Highlights

- Production exceptions can now be mapped back to Viandly application source, making unexpected
  failures substantially easier to diagnose.
- Diagnostic handling continues to exclude recipe content, scans, account identity, AI prompts,
  transcripts, credentials, request bodies, screenshots, and local variables.
- Viandly's operator receives alerts for new, reappeared, and regressed production issues.

## Tester Guidance

There is no new tester workflow in this release. If Viandly presents an unexpected-error recovery
page, retry once and report only the displayed error reference. Do not include private recipe text,
scans, provider credentials, or screenshots unless support asks for the minimum information needed.

## Compatibility

This release does not change the database schema or REST API version. Existing recipes, imports,
scanner deliveries, cookbook projects, account archives, authentication methods, and AI provider
configuration remain compatible.
