# Viandly 0.9.0-beta.14

Released: July 25, 2026

This beta update makes scanner failures easier to understand and recover from, reduces distracting
recipe comparisons, and improves editing and scan review across desktop and tablet layouts.

## Highlights

- Scanner deliveries now provide access to the retained original page before processing, whether
  automatic AI scanner processing is enabled or disabled.
- Scanner-backed failed drafts retain access to the original page so it can be inspected before
  retrying AI or choosing manual recovery.
- Malformed AI responses now include a short, plain-text response excerpt to help explain the
  failure without retaining the complete provider response.
- Tablet and phone draft review now focuses on editable source text while providing one clear
  action for opening the full retained scan.
- Related-recipe matching now requires stronger ingredient overlap, reducing unrelated suggestions
  caused by a few common ingredients.
- Recipe editing now includes **Cancel** beside **Save changes**, returning to the previous page
  without saving.
- Scanner Help now covers image-only PDFs, AI failure recovery, and scanner software that can add
  searchable text.

## What To Test

Open a scanner delivery before processing and confirm **View scanned page** opens its retained PDF
or image. The action should be available with automatic AI scanner processing either enabled or
disabled.

For a scanner-backed AI import failure, confirm the failed page still offers the original scan. A
malformed-response failure should also show a separate **AI response excerpt**. Retry with AI or
switch to manual recovery and confirm the source remains available.

On an iPad or narrow desktop viewport, confirm draft review does not show competing scan viewers.
Use the dedicated action to open the retained scan when comparison is needed.

Edit a recipe, make an unsaved change, select **Cancel**, and confirm the prior page is restored
without saving. Clearly unrelated recipes sharing only a few pantry ingredients should no longer
appear as similar during import review.

## Compatibility

Existing recipes, scanner deliveries, and import drafts remain compatible. This release does not
require a database migration.
