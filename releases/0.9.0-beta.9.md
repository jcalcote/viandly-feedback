# Viandly 0.9.0-beta.9

Released: July 24, 2026

This closed-beta update makes scanner-assisted import more resilient and allows one scanned
delivery to produce several reviewable recipes without splitting connected preparations
incorrectly.

## Highlights

- Added dependency-aware multi-recipe extraction. One scanner delivery can create separate drafts
  for as many as eight independent recipes.
- Kept connected preparations together. A base preparation and directions that consume it, such as
  a dry mix used to make pizza dough, remain one recipe with linked components.
- Made multi-draft creation atomic. Viandly either accepts the complete validated result or retains
  the recovered source text for correction; it does not silently discard individual candidates.
- Preserved useful AI transcription when recipe structuring fails. Recovered text can be corrected,
  analyzed again as text, converted manually, or reanalyzed from the retained scan.
- Retained private scanner images and PDFs through source and draft review so quantities, units,
  temperatures, and reading order can be checked against the original pages.
- Deferred scanner-object cleanup until every draft produced from the delivery has been saved or
  discarded, while preserving normal retention expiry.
- Added rejection email feedback when a recognized scanner address cannot accept a delivery because
  access, attachment, or temporary-capacity limits prevent intake.
- Improved Inbox consistency for scanner, source-review, and draft states, including clearer active
  processing feedback and unfiltered return after queued scanner analysis.

## Tester Guidance

Send a scan containing two independent recipes to your scanner receiving address and select
**Analyze with AI**. After processing, both recipes should appear as separate draft rows in
**Inbox**. A multi-part preparation whose later section consumes an earlier mix, sauce, dough,
starter, or similar component should remain one draft.

Open each resulting draft and compare it with the retained scanner pages. Saving the first draft
must not remove those pages while another related draft remains under review. If AI reads the page
but cannot produce a valid structured result, open the resulting **Needs review** source item to
correct or reuse the recovered text.

## Release Identity

The product version is `0.9.0-beta.9`, with source tag `v0.9.0-beta.9`. The About and Help
interfaces show the corresponding 12-character source revision.

## Compatibility

This release adds a data-preserving relationship between import drafts and their retained source
material. Existing scanner deliveries, source captures, import drafts, recipes, archives,
authentication methods, and AI provider connections remain supported. The REST API version is
unchanged.
