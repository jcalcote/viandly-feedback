# Viandly 0.9.0-beta.18

Released: July 27, 2026

This beta update makes Viandly's public policies easier to inspect before joining and adds
privacy-bounded production error monitoring so unexpected failures can be diagnosed proactively.

## Highlights

- A public Trust Center now links Viandly's Terms of Service, Privacy Policy, copyright process,
  open-source notices, Help Center, and support contact.
- Prospective users can review legal and privacy documents from the anonymous landing page and
  sign-in screen. Signed-in users can reach them from the account menu.
- Unexpected application failures now provide **Try again**, **Back**, and **Home** recovery
  actions instead of relying on a generic framework error page.
- A short support reference is shown when one is available, without exposing private recipe,
  scanner, account, or AI content.
- Production errors are grouped by release and can alert the Viandly operator without enabling
  session replay, tracing, profiling, screenshots, or private-content capture.

## Tester Guidance

Review **Trust & Legal** from the public footer or account menu and confirm that the documents and
support links remain usable on desktop, tablet, and phone layouts.

If Viandly displays an unexpected-error recovery page, retry once and report only the displayed
error reference. Do not include private recipe text, scans, provider credentials, or screenshots
unless support asks for the minimum information needed.

## Compatibility

This release does not change the database schema or REST API version. Existing recipes, imports,
scanner deliveries, cookbook projects, account archives, and authentication methods remain
compatible.
