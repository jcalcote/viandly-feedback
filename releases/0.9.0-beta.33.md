# Viandly 0.9.0-beta.33

Released: November 10, 2026

This beta makes it easier to start a recipe with AI assistance, especially on a phone.

## Highlights

- Describe a recipe idea without filling in the manual recipe fields first. **Create AI-assisted
  draft** now starts the development draft instead of stopping at an empty required field.
- While the AI panel is open on **New Recipe**, the manual **Create recipe** action is hidden so
  it is clearer which action will send your idea to the assistant.
- The recipe-entry help article explains the manual and AI paths. Underlying dependencies also
  received a maintenance update.

## Try It

With an AI provider configured, open **New Recipe**, choose **Get help from AI**, describe a dish,
and select **Create AI-assisted draft**. The resulting draft should be editable, and you can ask
for further changes there. Manual entry still works when the AI panel is closed.

If this does not work as expected, report the device and browser in the
[feedback tracker](https://github.com/jcalcote/viandly-feedback/issues). Please do not post
private recipe content publicly.

## Compatibility

No database migration or account-data conversion is required. Existing recipes and development
drafts remain intact.

## Release Identity

The product version is `0.9.0-beta.33` and the source tag is `v0.9.0-beta.33`. **About Viandly**
shows the revision running in production.
