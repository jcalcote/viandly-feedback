# Viandly 0.9.0-beta.12

Released: July 25, 2026

This beta update makes entering recipes by hand substantially faster while preserving the structured
ingredient data needed for scaling, shopping lists, cooking, and baking tools.

## Highlights

- Replaced the default ingredient field grid with compact natural-language entry. Type an
  ingredient as it appears in a recipe, press Enter, and continue with the next line.
- Added multiline ingredient paste and explicit section creation for quickly entering complete
  ingredient lists.
- Added immediate, deterministic interpretation of amounts, units, preparation phrases, notes,
  package sizes, intentionally unmeasured ingredients, and ambiguous quantities.
- Added clear **Ready**, **As written**, and **Needs review** states. Viandly preserves the user's
  original line when it cannot safely interpret part of an ingredient.
- Kept expandable structured controls for precise corrections without requiring every ingredient
  to be entered field by field.
- Preserved authored ingredient text and interpretation details through recipe editing, scaling,
  Cooking Mode, print, shopping lists, and portable account archives.
- Added contextual Help and a complete guide to entering recipes by hand.
- Fixed retained scanner-page previews so authenticated users can refer to their original private
  scans while reviewing or editing a recipe.

## Tester Guidance

Create or edit a recipe and enter several ingredients through the compact ingredient field. Include
a fraction, a preparation phrase, an item without a measured amount, and an unfamiliar unit. Confirm
that Viandly interprets safe lines, flags uncertain lines without discarding text, and allows any row
to be expanded for structured correction.

Paste a multiline ingredient list and confirm that each nonblank line becomes one ingredient. Add a
named ingredient section, save the recipe, then verify the result in recipe detail, scaling, print,
Cooking Mode, and a shopping list.

For a recipe created from a retained scanner delivery, open its original source and confirm that the
private PDF or image appears in the review viewer.

## Release Identity

The product version is `0.9.0-beta.12`, with source tag `v0.9.0-beta.12`. The About and Help
interfaces show the corresponding 12-character source revision.

## Compatibility

Existing recipes remain compatible. Structured ingredient values continue to drive conversions and
scaling, while the new authored-text and interpretation fields are populated for newly entered or
revised ingredients.

This release adds ingredient authorship and interpretation metadata through an additive database
migration. Existing recipes, imports, shopping lists, scans, images, and account archives are
preserved. The REST API version is unchanged.
