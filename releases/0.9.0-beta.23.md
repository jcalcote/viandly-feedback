# Viandly 0.9.0-beta.23

Released: August 5, 2026

This beta update improves the recipe detail page so ingredients, directions, notes, and source
information are easier to scan while preserving the compact library-oriented view.

## Highlights

- Ingredients now use clear bullets with tighter spacing between items.
- Directions use more readable numbered markers and compact step spacing.
- Recipe notes now span the available content width instead of being constrained to one column.
- Attribution labels and values use regular weight so longer source notes do not visually dominate
  the recipe.
- Section spacing has been refined to improve readability without making recipes unnecessarily
  long.

## Tester Guidance

- Open recipes with short and long ingredient lists and confirm each item remains easy to scan.
- Review recipes with several direction steps and confirm the numbering is clear without excessive
  vertical space.
- Check recipes with long notes and attribution text on desktop, tablet, and phone layouts.

## Release Identity

The product version is `0.9.0-beta.23` and the source tag is `v0.9.0-beta.23`. The About and Help
interfaces show the exact 12-character source revision used by the production build.

## Compatibility

This is a presentation-only release. It does not change the database schema or existing recipe,
account, import, image, cookbook, billing, or AI data.
