# Viandly 0.9.0-beta.8

Released: July 24, 2026

This closed-beta update makes the unified Inbox reliably reflect asynchronous and externally
delivered work without requiring navigation or a manual page reload.

## Highlights

- Fixed empty and filtered Inbox views so scanner deliveries and other new work appear after they
  arrive.
- Fixed existing Inbox rows so background status, error, attachment, source-review, and linked
  recipe-title changes become visible automatically.
- Fixed removed or converted work so stale rows and pagination counts disappear automatically.
- Added immediate checks when the Inbox opens, regains focus, becomes visible, or returns from the
  browser page cache.
- Replaced repeated full-list polling with a lightweight private change check. The full server
  route refreshes only when the signed-in account's Inbox data actually changes.
- Added account-isolation and regression coverage for Inbox additions, updates, and removals.
- Updated several production dependencies to patched compatible releases after new upstream
  security advisories were published.

## Tester Guidance

Leave the Inbox open while sending a recipe to your scanner receiving address. The new delivery
should appear within approximately five seconds after Viandly records it. Subsequent processing
states and the transition into source or draft review should update in the same view.

The same behavior applies to empty Inbox views, active searches and filters, background imports,
source-review results, and rows removed by processing or cleanup.

## Release Identity

The product version is `0.9.0-beta.8`, with source tag `v0.9.0-beta.8`. The About and Help
interfaces show the corresponding 12-character source revision.

## Compatibility

This release does not change the relational database schema or REST API version. Existing imports,
scanner deliveries, source captures, drafts, recipes, authentication methods, and provider
connections remain unchanged.
