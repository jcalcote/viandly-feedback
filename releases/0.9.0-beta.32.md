# Viandly 0.9.0-beta.32

Released: October 17, 2026

This beta improves the reliability of inbox processing. An error in one background task should no
longer leave other queued items waiting indefinitely.

## Highlights

- Inbox processing recovers from temporary errors and continues working through queued items.
- Background processing restarts automatically after a process exit.
- Underlying application dependencies received a maintenance update.

## Try It

No action is required. Previously queued inbox work has resumed. If a new item remains queued for
an unusually long time, report it in the [feedback tracker](https://github.com/jcalcote/viandly-feedback/issues)
with the version shown on **About Viandly**. Do not post private recipe or scan contents publicly.

## Compatibility

Existing inbox items, drafts, and recipes are preserved. No database migration is required.

## Release Identity

The product version is `0.9.0-beta.32` and the source tag is `v0.9.0-beta.32`. **About Viandly**
shows the revision running in production.
