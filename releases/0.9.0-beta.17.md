# Viandly 0.9.0-beta.17

Released: July 27, 2026

This beta update adds stable references between recipes at the exact point where another recipe
matters.

## Highlights

- Type `@` in a recipe description, note, or instruction to search for and insert another recipe.
- Use the touch-friendly reference button when typing `@` is inconvenient.
- Connect an ingredient directly to another prepared recipe, such as a sauce, dough, or component.
- Recipe views omit the editing `@` and present the referenced title as emphasized linked text.
- Hover, keyboard focus, and touch can open a compact preview before navigating to the referenced
  recipe.
- Cook Mode, private shares, printouts, and cookbook editions preserve readable reference text.
- A read-only **Referenced recipes** panel indexes the references already embedded in a recipe
  without creating a separate relationship list to maintain.
- The recipe-library search field restores a consistent leading search icon while retaining one
  aligned clear control.
- Help now explains insertion, editing, presentation, privacy, rename, and deletion behavior.

## Tester Guidance

Edit a recipe and type `@` in its description, notes, or an instruction step. Select a matching
recipe, save, and confirm that the recipe name appears without the `@` in the detail view. Point to
or select the name to open its preview, then use **Open recipe**.

Expand an ingredient, select **Use another recipe**, and confirm that the normal ingredient fields
remain available. After saving, open **Referenced recipes** and confirm that each referenced recipe
appears once.

Try a public or privately shared source recipe that references a private recipe. A reader without
independent access should see the authored words but no link, preview, or panel entry for the
private target.

## Compatibility

Existing recipes remain compatible and require no data rewrite. Account archives preserve
references when both recipes are available and retain ordinary readable text when a target cannot
be restored.

This release does not change the REST API version.
