# Viandly 0.9.0-beta.15

Released: July 26, 2026

This beta update makes retained scanner documents practical to inspect on tablets and desktop
browsers, while simplifying import review around one consistent source workspace.

## Highlights

- Retained scanner PDFs now use a Viandly viewer with explicit page and zoom controls.
- The viewer remembers the selected scan file, PDF page, and zoom level during the browser session.
- Zoomed pages can be scrolled fully to both the left and right edges.
- Scanner-backed draft review now uses one responsive source workspace: beside the recipe on
  desktop and below it on tablet or phone.
- **Source Text** and **Original Scan** remain available at every supported screen width.
- Successful draft review no longer shows a duplicate scan card or separate-window action. The
  viewer's expand control provides full-page inspection.
- Scanner failure and recovery screens continue to provide retained source evidence.
- The old selected-source classification toolbar has been removed. Source material now serves as
  reference while AI repair and normal draft editing handle corrections.

## What To Test

Open a scanner-backed draft on a desktop browser. Select **Original Scan**, page through a
multipage PDF, change the zoom level, and expand the viewer. Unsaved draft work should remain
available.

Repeat the review on an iPad, phone, or narrow desktop window. The source workspace should move
below the recipe while retaining both **Source Text** and **Original Scan**. At greater than 100%
zoom, horizontal scrolling should reach both page edges.

Successful draft review should no longer show a second retained-scan card or the retired
source-classification buttons. Scanner-backed failure and recovery pages should still provide
access to retained source files.

## Compatibility

Existing recipes, imports, scanner deliveries, and retained scanner files remain compatible.
Scanner evidence continues to follow existing authorization and temporary-retention rules.

This release does not require a database migration.
