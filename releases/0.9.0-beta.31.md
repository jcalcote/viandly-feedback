# Viandly 0.9.0-beta.31

Released: October 9, 2026

This beta makes in-person shopping lists easier to build and use during a store trip.

## Highlights

- On a new list, **Add to list** opens automatically. Choose a store once and enter several items
  for it with Enter. Fold the panel away when you are ready to shop; Add recipes, Add staples, and
  Paste items stay inside it.
- Create an in-person store directly from the list. If pasted items mention an unknown store,
  Viandly asks whether to create it while preserving the text so you can correct a typo instead.
- Purchased items remain crossed out in their original store section instead of moving to a
  separate Purchased section. Restoring one requires confirmation.
- Shopping Help has been updated for this workflow.

## Try It

- Build a new list with several items for one store, then switch to another store.
- Paste items under a new `Store name:` heading and review the store-creation prompt.
- Check off an item, confirm it stays in place, then try canceling and confirming a restore.
- Report unexpected behavior in the [feedback tracker](https://github.com/jcalcote/viandly-feedback/issues).

## Compatibility

Existing shopping lists and purchase history are preserved. No database migration is required.
