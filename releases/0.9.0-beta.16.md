# Viandly 0.9.0-beta.16

Released: July 26, 2026

This beta update makes recipe tags reliable when AI providers or users separate them with
semicolons instead of commas.

## Highlights

- Recipe entry now accepts commas, semicolons, or a mixture of both between tags.
- AI import, AI draft repair, and recipe development now request comma-separated tags.
- Imported tag lists are normalized to a consistent comma-separated presentation during review.
- Tags are trimmed, normalized, and deduplicated before recipes are saved.
- Existing AI-generated tag lists that were stored as one semicolon-separated tag have been
  repaired into separate tags.

## What To Test

Create or edit a recipe and enter several tags using semicolons, commas, or a mixture of both.
After saving, each value should appear as a separate tag and repeated values should appear only
once.

Import a recipe with AI and review its tag field. Suggested tags should normally use commas. Even
if an AI provider returns semicolons, saving the recipe should still create separate tags.

Search or filter using tags from previously imported recipes and confirm that each repaired tag can
be selected independently.

## Compatibility

Existing recipes and ordinary tags remain compatible. This release does not require a database
migration.
