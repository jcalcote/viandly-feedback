# Viandly 0.9.0-beta.11

Released: July 25, 2026

This beta update makes user-owned AI spending visible and controllable in terms of the Viandly
features that consume it.

## Highlights

- Added current-month AI usage summaries for recipe scanning, recipe import, draft adjustment,
  recipe development, cookbook design, and Cook Assist.
- Added an independent enable switch and optional monthly estimated-cost guardrail for each
  user-facing AI feature.
- Added expandable provider and model details with request counts, input and output tokens, audio
  use, source-image counts, and estimated provider cost.
- Added durable, idempotent accounting across OpenAI-compatible, Anthropic, Google Gemini, and
  OpenAI Realtime responses. Retries that reach a provider are represented as distinct work, while
  duplicate reports of the same response are counted once.
- Added a dated pricing catalog for recognized models. Unknown or custom model prices remain
  explicitly unpriced instead of receiving a guessed cost.
- Added aggregate AI activity to the administrative monetization view without exposing account
  identities, prompts, recipes, source text, images, responses, or credentials.
- Expanded AI Provider help with feature controls, spending-limit behavior, privacy boundaries, and
  the distinction between Viandly estimates and authoritative provider billing.

## Tester Guidance

Open **Account Settings - AI Provider** and review **AI features**. Disable one feature, save it, and
confirm the corresponding workflow explains that it is unavailable. Re-enable it and optionally set
a small monthly limit.

Use one or more AI workflows, then return to AI Provider settings. Confirm usage appears under the
feature that initiated the work. Expand **Usage details** to inspect its provider and model. Scanner
work should report source images, Cook Assist should report audio tokens, and text workflows should
report input and output tokens when the provider supplies them.

Cost is always labeled as an estimate. Compare it with the provider dashboard if desired, but treat
the provider invoice and provider-side spending controls as authoritative.

## Release Identity

The product version is `0.9.0-beta.11`, with source tag `v0.9.0-beta.11`. The About and Help
interfaces show the corresponding 12-character source revision.

## Compatibility

Existing provider connections remain active. Every AI feature defaults to enabled with no Viandly
monthly limit, so existing workflows continue without account reconfiguration.

This release adds account-owned AI feature preferences and immutable usage events through additive
database migrations. Existing recipes, imports, scans, cookbooks, Cook Assist sessions, and
credentials are preserved. Historical AI requests cannot be reconstructed and are not backfilled;
usage reporting begins with this release. The REST API version is unchanged.
